## 🚀 Getting Started

### 🔧 Prerequisites

- Android Studio Flamingo+  
- JDK 17+  
- Firebase Account  

---

### ⚙️ Setup

1. Clone the repository:
```bash
git clone https://github.com/kunaljit3006/Connect.git
```

2. Firebase setup:
- Create project in Firebase Console
- Add Android app
- Download google-services.json
- Place it inside /app
- Enable:
  - Email/Password Authentication
  - Firestore Database

3. Run the app
